# 한끼 실행과 시연

## 로컬 실행

JDK 21을 설치한 환경에서 프로젝트 폴더를 엽니다. `.env`가 없으면 `.env.example`을 복사해 만들고 `OPENAI_API_KEY`를 입력합니다. 레시피와 재료 사진 인식에는 `OPENAI_MODEL`, 완성 음식 사진 생성에는 `OPENAI_IMAGE_MODEL`을 사용합니다.

```powershell
.\gradlew.bat bootRun
```

브라우저에서 http://localhost:3000 을 엽니다. 서버를 종료하려면 실행한 터미널에서 Ctrl+C를 누릅니다.

## 시연 순서

1. 대화창에 달걀, 토마토, 대파를 입력합니다. 재료 사진을 첨부할 때는 AI가 인식한 재료명을 확인하고 수정합니다.
2. 보유 양념, 제외 재료, 숙련도와 인분을 설정하고 추천을 요청합니다. AI가 조건에 따라 메뉴를 생성하므로 시연마다 메뉴와 시간이 달라질 수 있습니다.
3. 추천 결과를 열어 재료 분량과 조리 단계를 확인합니다. 음식 사진은 카드나 상세 화면에서 처음 필요할 때 생성됩니다.
4. 조리 모드에서 단계별 불 세기와 시간을 확인하고 타이머를 실행합니다.
5. 레시피를 북마크하고 저장 탭에서 다시 엽니다. 커뮤니티에는 직접 촬영한 사진과 후기를 올릴 수 있습니다.

## 빌드

```powershell
.\gradlew.bat build
```

`build/libs/hankki.jar`를 프로젝트 폴더에서 `java -jar build/libs/hankki.jar`로 실행할 수 있습니다. 음식 사진은 `.recipe-photos/`, 커뮤니티 게시글과 첨부 사진은 `.community/`에 보관합니다.
