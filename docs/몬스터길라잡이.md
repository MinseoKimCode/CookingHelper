# 한끼 몬스터 길라잡이

몬스터는 앱 사용의 다음 행동을 알려주는 동행자입니다. 안내는 스크롤 밖의 공통 영역에 두고,
상세·조리·커뮤니티 창을 열면 해당 창 안으로 옮겨갑니다. 캐릭터를 누르면 안내를 펼칠 수 있습니다.
일반 화면에서는 안내 행동과 주요 화면 이동을 제공하고, 상세 창에서는 현재 작업에 집중합니다.

## 상태와 표현

| 상황 | 표현 | 안내 |
| --- | --- | --- |
| 대기 | 숨쉬기, 눈 깜빡임, 가벼운 손짓 | 재료 입력·사진 선택 시작 방법 |
| 재료 입력 | 손을 들고 눈을 맞춤 | 쉼표 입력과 재료 추가 방법 |
| 사진 처리 | 돋보기를 움직이며 살핌 | 인식 대기 및 결과 확인·수정 |
| 추천·설명·목록 요청 | 노트북 앞에서 타이핑, 시선 이동 | 처리 중임을 알림 |
| 조리 | 냄비·숟가락·김 표현 | 현재 단계, 타이머와 익힘 확인 |
| 성공 | 손을 들고 작은 점프, 미소·반짝임 | 추천·저장·등록·요리 완성 반응 |
| 실패·빈 추천 | 고개를 갸웃, 물음표 | 재시도·재료 수정 방법 |

## 구현

- `mobile/components/Monster.tsx`: 기존 몸/모자/손 이미지를 조합한 React Native Animated 리그
- `mobile/components/GuideCard.tsx`: 몬스터와 문맥 안내, 펼치기·다음 행동
- `mobile/guide.ts`: 화면·진행 작업·일시 반응의 우선순위
- `mobile/hooks/useGuideActivity.ts`: 화면에서 활동을 등록하고 떠날 때 자동 해제
- `AppProvider`: 추천 진행 상태, 성공/실패 반응, 모달 안내 위치 관리

분석·추천 같은 진행 작업을 짧은 축하 반응이 가리지 않습니다. 단순 입력 대기 중에는 축하 반응을
먼저 보여줍니다. 반응 타이머는 새 반응으로 교체되고 컴포넌트 정리 시 취소합니다.

애니메이션은 React 재렌더 대신 Animated 값을 사용합니다. 네이티브에서는 native driver를 사용하며,
웹에서는 같은 상태를 Animated로 표현합니다. 앱이 백그라운드로 이동하거나 컴포넌트가 사라지면
루프를 정리합니다. 시스템 동작 줄이기 설정이 켜져 있으면 정지된 표정·소품과 텍스트 안내를 유지합니다.
화면 읽기 도구에는 반복 애니메이션 대신 바뀐 안내 제목을 전달합니다.

새 이미지를 생성하거나 캐릭터 디자인을 바꾸지 않고 기존 초록 몬스터 자산을 사용했습니다.
브라우저와 실기기에서의 동작·배치 시각 검증은 별도로 필요합니다.

## AI 안내와 사용자 행동 기반 튜토리얼

사용법 배우기는 9단계이며, 실제 재료 추가·추천 응답·레시피 열기·요리 완성·북마크·커뮤니티 열기를
확인해야 다음 단계로 이동합니다. 시작·설정 확인·마치기만 사용자 확인 버튼으로 진행합니다.
설명만 읽고 조리나 추천이 완료된 것으로 처리하지 않습니다. 커뮤니티 게시글 작성은 강제하지 않습니다.

튜토리얼 목표·동작·확인 이벤트는 `mobile/tutorial.ts`가 정의합니다. 해당 입력 영역·북마크를 강조하고,
재료·설정·추천 버튼과 요리 시작 버튼까지 안내 위치를 맞춥니다. 진행 상태는 기기에 저장하며,
중단하거나 다시 시작할 수 있습니다.

`POST /api/guide`는 현재 재료, 제외 설정, 숙련도, 실제 레시피와 조리 단계에 근거해 질문에 답합니다.
튜토리얼 설명도 이 API로 단계별 한 번 생성합니다. 사용자 입력마다 호출하거나 애니메이션 프레임마다
호출하지 않습니다. AI가 반환할 수 있는 값은 title과 message뿐이며 버튼 실행, 모션 변경, 진도 완료 권한은 없습니다.
질문 답변과 튜토리얼 설명은 AI 출처를 구분합니다. AI 호출이 실패하면 기본 조작 안내와 명시적인 오류를 제공합니다.

대기 중에는 숨쉬기와 눈 깜빡임만 유지하고, 손짓·고민·분석·조리·축하는 사용자 행동 및 실행 중인 작업에
연결합니다. 튜토리얼 설명에서는 해당 단계의 정해진 동작을 시연합니다.
