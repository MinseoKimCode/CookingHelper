# React Native 전환 현황

2026-11-25 기준입니다.

2026-11-26 추가 구현(타이머 알림, H2, 커뮤니티 관리, 백업 등)은 [운영 및 유지보수](security-and-maintenance.md)를 참고하세요. 아래 내용은 전환 당시 기록입니다.

## 변경한 구조

기존 HTML/CSS/DOM 스크립트 대신 Expo 앱 진입점과 React Native 화면을 사용합니다.
루트 `npm start`는 Expo를 실행하며, 서버는 `npm run api`로 별도 실행합니다.
이전 Node 서버, 프런트엔드, 테스트와 기획 문서는 전환 당시 별도로 보관했으며, 2026-11-26 사용자 확인 후 보관 폴더를 삭제했습니다.

API 서버를 React Native로 바꾸지는 않습니다. React Native는 클라이언트 UI이며,
AI 키 보호·서버 저장·응답 검증은 Spring Boot가 담당합니다. 중복된 Node 서버는 실행하지 않습니다.

## 클라이언트 변경

- DOM 조회/innerHTML을 React Native View, Text, TextInput, Pressable, Image, Modal로 교체
- 웹 전용 파일 입력/Canvas 대신 Expo ImagePicker와 ImageManipulator로 촬영·선택·JPEG 압축
- localStorage 직접 접근 대신 AsyncStorage 서비스
- 요청 취소·오래된 추천 응답 무시·시간 제한을 API/상태 계층에 구현
- 화면별 로딩, 빈 결과, 오류 재시도와 게시/댓글 중복 제출 방지
- 날짜 기반 타이머로 앱 복귀 시 남은 시간 재계산 (백그라운드 알림은 미구현)
- 기존 숙련도별 공통 문장 덧붙이기/어미 치환 제거, 서버에서 받은 조리 설명 표시
- 모바일 하단 탭과 넓은 웹 좌측 메뉴, 안전 영역, iOS 키보드 대응

## 서버 변경

- 고정 레시피 대체 경로 제거 (이전 코드와 레시피 데이터 보관 폴더는 이후 삭제)
- 사진 파일은 API의 정적 리소스로 분리
- Expo 웹 개발 출처를 설정 가능한 CORS 정책으로 허용
- Expo 웹 export 결과를 선택적으로 API jar에 포함
- 실제 Java 서버 기준 추천·필터·인분·제외 재료·CORS·커뮤니티 통합 테스트

## 유지한 정책과 후속 개선

화면 전환 이후 추천 생성과 몬스터 AI 안내도 연결했습니다.

- 메뉴 탐색·맞춤 추천·추천 순서·분량·숙련도별 설명·대체안은 AI가 생성하고 별도 AI 검토를 통과해야 표시
- 고정 정렬과 첫 두 재료 기반 중복 시그니처 제거, 동일 이름 중복·제외 재료·필터·분량 검증은 유지
- 추가 구매 허용 수와 요청 메뉴 수는 사용자 설정으로 전달
- 동의어/알레르기 기본 매핑과 입력 범위 검사는 안전장치로 유지하고 복합 식품 의미 검토도 AI에 요청
- 몬스터 움직임과 튜토리얼 진도는 사용자 행동 이벤트로 결정, AI는 설명과 질문 답변만 생성
- 튜토리얼 진도 저장·영역 강조·해당 영역으로 스크롤, AI 설명은 단계별 한 번씩 요청
- 회원 로그인/권한 관리 없음, 커뮤니티 viewer UUID는 인증 수단이 아님
- 저장은 기기별, 계정 동기화 없음
- 같은 출처에 남아 있는 기존 savedRecipes 스냅샷은 자동 가져오기, 다른 포트/기기와 자동 공유되지 않음
- 앱 백그라운드 타이머 알림, APK/IPA 배포 설정, 실기기 카메라 QA는 후속 확인 필요

수행한 검증: TypeScript, 웹 export, Android/iOS Hermes export, API 통합 테스트.
새 서버 키 적용 후 실제 OpenAI 길라잡이 답변과 메뉴 생성·독립 검토가 성공했습니다.
실기기 및 브라우저 시각 QA는 별도입니다. UI 자동화는 브라우저 URL 확인 실패로 중단됐습니다.
