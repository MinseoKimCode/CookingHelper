# 실행과 시연

## 로컬 실행

Node.js 22 이상이 필요하다. 별도 패키지 설치는 필요 없다.

```powershell
cd 'C:\Users\milsx\Desktop\요리도우미'
npm.cmd start
```

브라우저에서 http://localhost:3000 을 연다. 종료는 실행한 터미널에서 Ctrl+C를 누른다. Windows PowerShell 실행 정책 때문에 `npm` 명령이 막히면 위와 같이 `npm.cmd`를 사용한다.

## AI 연결

`.env.example`을 `.env`로 복사하고 서버에서만 사용하는 API 키를 넣는다.

```powershell
Copy-Item .env.example .env
```

```dotenv
OPENAI_API_KEY=실제_API_키
OPENAI_MODEL=gpt-4.1-mini
PORT=3000
```

서버를 재시작한다. 계정에서 사용할 수 있는 이미지 입력·구조화 출력 지원 모델로 `OPENAI_MODEL`을 변경할 수 있다. 키를 넣었다는 상태 표시만으로 API 호출 성공을 보장하지 않으므로 실제 사진으로 확인해야 한다. 키를 GitHub 또는 브라우저 코드에 넣지 않는다. `.env`는 Git에서 제외되어 있다.

사진은 JPG·PNG·WEBP, 최대 5MB를 지원한다. 사진 분석 시 외부 OpenAI API로 전송되며 서버 파일로 저장하지 않는다. API 요청은 `store:false`로 전송한다. 인식 결과를 확인하고 재료명을 수정한 뒤 추가한다. 모델 접근 권한·사용 한도·네트워크에 따라 실패할 수 있으며 오류를 화면에 표시한다.

구현 참고: [OpenAI 이미지 입력 공식 문서](https://developers.openai.com/api/docs/guides/images-vision).

## 대표 시연 순서

1. 기본 재료 ‘달걀·토마토·대파’와 초보·2인분을 확인한다.
2. ‘나에게 맞는 요리 찾기’를 누르고 토마토 달걀 볶음을 연다.
3. 추천 이유, 재료 분량, 기본 양념과 궁합을 확인한다.
4. ‘요리 시작하기’를 눌러 단계와 타이머를 시연한다.
5. 김치와 밥을 추가해 김치볶음밥을 확인한다.
6. 제외 재료에 달걀을 입력한 후 다시 추천해 달걀 요리가 빠지는지 확인한다.
7. 마음에 드는 요리의 하트를 누르고 ‘저장한 레시피’를 확인한다.
8. AI 연결을 완료했다면 냉장고 사진 분석 → 재료 수정 → 확인 후 추가를 시연한다.

## 검증

```powershell
npm.cmd test
node --check public/app.js
node --check server.mjs
```

외부 라이브러리 없이 Node.js 기본 HTTP 서버, fetch, 테스트 러너를 사용한다. 인터넷 연결이 없어도 시스템 글꼴과 예시 일러스트로 텍스트 추천 시연이 가능하다.

## 주요 파일

- `server.mjs`: 정적 파일 제공, 입력 검사, 추천·사진 분석·AI 설명 API.
- `lib/recipes.mjs`: 샘플 레시피, 재료 정규화, 필터 및 추천 점수.
- `public/`: 한국어 UI, 반응형 디자인, 저장·조리·타이머 동작.
- `tests/`: 추천 로직과 HTTP API 자동 테스트.
- `docs/진행상황.md`: 제출 가능한 개발 진행상황과 다음 일정.

현재 서버는 로컬 PC의 127.0.0.1에만 바인딩한다. 공개 서비스로 배포할 때에는 HTTPS, 요청 제한, 사용자별 데이터 처리 및 운영 설정을 추가해야 한다.
