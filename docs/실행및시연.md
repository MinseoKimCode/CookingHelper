# 실행과 시연

자세한 설치·네트워크 설정은 루트 README를 참고하세요.

## 개발 실행

1. `npm.cmd run api`로 Spring Boot 서버를 실행합니다.
2. 별도 터미널에서 `npm.cmd start`를 실행합니다.
3. Expo Go로 QR을 열거나 `npm.cmd run web`으로 브라우저에서 엽니다.
4. 실제 휴대폰에서는 PC와 같은 Wi-Fi 및 API LAN 주소를 사용합니다.

## 시연 순서

1. 내 냉장고에서 `달걀, 토마토, 대파`를 입력하고 추가합니다.
2. 보유 양념에 `식용유, 소금`, 초보, 2인분을 선택하고 추천받습니다.
3. 추천의 부족한 재료, 인분, 출처, 시간과 난이도를 확인합니다.
4. 레시피를 저장하고 상세를 열어 조리 순서·재료를 봅니다.
5. 요리 시작으로 단계별 안내와 타이머의 시작·일시 정지·이전/다음을 확인합니다.
6. 저장 탭에서 북마크를 다시 엽니다. 앱을 재실행해 보존 여부도 확인합니다.
7. AI가 연결되어 있다면 재료 사진을 촬영하거나 선택하고, 인식 결과를 수정해 추가합니다.
8. 커뮤니티에 요리 후기를 올리고 사진, 좋아요, 댓글을 확인합니다.

메뉴 탐색·추천·사진 인식·AI 질문은 유효한 API 키가 필요합니다. AI 실패 시 고정 메뉴로 대체하지 않습니다.
저장한 레시피와 기본 사용 안내는 AI 연결 없이도 이용할 수 있습니다.
몬스터의 사용법 배우기를 시작하면 재료 추가·설정 확인·추천 완료·레시피 열기·요리 완성·저장·커뮤니티 열기에 맞춰 진도가 진행됩니다.
몬스터를 눌러 안내를 펼치고 현재 레시피에 관한 질문도 해보세요. 모션과 앱 행동은 AI 답변과 별도로 제어됩니다.

## 배포용 웹

```powershell
npm.cmd run build:web
npm.cmd run build:api
java -jar build/libs/hankki.jar
```

웹과 API를 같은 서버에서 실행하는 경우 브라우저에서 http://localhost:3000 으로 접속합니다.
독립 웹 호스팅이나 네이티브 앱에서는 빌드할 때 공개 HTTPS API 주소를 명시합니다.
