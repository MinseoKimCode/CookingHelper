# 요리도우미 개발 진행상황

작성일: 2026년 10월 28일

## 제출용 진행상황 요약

기획 문서를 바탕으로 냉장고 재료 기반 요리도우미의 로컬 실행 가능한 MVP를 구현했다. 서비스 이름은 ‘한끼’로 정했으며, 크림색 배경과 초록색을 중심으로 편안한 주방 분위기의 화면을 구성했다. 데스크톱에서는 재료 입력과 추천 결과를 나란히 배치하고, 모바일에서는 세로 흐름으로 사용할 수 있도록 반응형 화면을 구현했다.

사용자는 보유 재료를 직접 입력하고 초보·중급·고급 숙련도와 1~6인분을 선택할 수 있다. 계란과 달걀 같은 재료 이름을 정규화하고, 보유 재료 비율·부족한 재료 수·숙련도 적합도를 기준으로 샘플 레시피를 추천한다. 제외 재료와 일부 알레르기 분류를 반영하며, 추천 결과에서 조리 시간·난이도·보유 재료 수·추가로 필요한 재료를 확인할 수 있다.

레시피 상세 화면에는 추천 이유, 재료별 분량, 기본 양념, 가능한 대체 재료, 재료 궁합, 조리 순서를 제공한다. 단계별 조리 모드와 일시 정지 가능한 타이머, 레시피 저장 기능도 구현했다. 인분에 따라 재료와 양념의 분량이 함께 바뀐다.

냉장고 사진 분석은 OpenAI Responses API를 호출하는 서버 기능과 인식 결과 확인·수정 화면까지 구현했다. API 키는 서버 환경변수로만 관리하며 사진을 서버 파일로 저장하지 않는다. 현재 실제 API 키를 연결하지 않았기 때문에 실제 사진 분석 성공과 AI 설명 품질은 검증하지 못했다. API 키 없이도 텍스트 기반 추천과 조리 안내를 시연할 수 있다.

현재 추천 데이터는 직접 작성한 샘플 레시피 6종이다. 외부 출처 및 실조리를 통한 검증을 마친 레시피 데이터베이스는 아직 구축하지 않았다. 완성 음식은 실제 사진 대신 예시 일러스트를 사용한다. 따라서 핵심 사용자 흐름을 시연할 수 있는 MVP 단계이며, 전체 프로젝트가 최종 완료된 상태는 아니다.

## 구현 현황

| 기능 | 상태 | 내용 |
| --- | --- | --- |
| 보유 재료 입력·수정·삭제 | 구현 | 태그, 빠른 추가, 브라우저 저장 |
| 숙련도·인분 선택 | 구현 | 숙련도에 따른 설명·추천 점수, 분량 환산 |
| 재료 기반 추천 | 구현 | 로컬 샘플 6종 검색, API 키 없이 동작 |
| 추천 이유·재료 궁합 | 구현 | 샘플 설명, 키 연결 시 AI 추가 설명 |
| 단계별 조리 안내 | 구현 | 단계 이동, 재료 재확인, 타이머 |
| 부족한 재료·대체안 | 구현 | 보유한 대체 재료만 제시, 기본 양념 별도 표시 |
| 제외 재료 | 구현 | 직접 재료명, 우유·밀·대두·달걀 분류 일부 반영 |
| 냉장고 사진 분석 | 연결 코드 구현 / 실 API 미검증 | 업로드, 서버 분석, 후보 수정 후 확정 |
| 레시피 저장 | 구현 | 현재 브라우저 localStorage 사용 |
| 모바일 대응 | CSS 구현 / 실기기 미검증 | 화면 폭에 따른 레이아웃 변경 |
| 완성 사진 | 미완료 | 현재 예시 일러스트로 표시 |
| 테스트 | 자동화 검증 | 추천 로직 및 HTTP API 테스트 |
| 배포·사용자 테스트 | 미진행 | 로컬 실행 MVP 단계 |

## 검증 범위와 한계

자동 테스트는 재료 정규화, 추천 우선순위, 제외 재료, 인분 환산, 대체안, 빈 결과, 레시피 필드, HTTP API 응답과 잘못된 요청 거절을 확인한다. 실제 AI 호출·브라우저 클릭·실제 조리·사용자 3명 테스트는 아직 수행하지 않았다. 건강 궁합은 질병 예방이나 치료 효과를 주장하지 않는 일반적인 식품군 설명만 제공한다. 복합 식품의 모든 성분과 알레르기를 자동 판별하지는 않는다.
